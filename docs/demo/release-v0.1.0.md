# v0.1.0 — Find useful resources across community-curated lists

Explore 3,037 real resources from three publicly discovered Awesome lists with
50,000+ observed stars. Search, filter by source, browse pages, inspect pinned
source revisions and read the original CC0 notices.

All crawling and catalogue processing happen locally. The Streamlit app reads a
versioned snapshot without a GitHub token, crawler or AI provider.

This is the first preview, not the finished release. It covers a reviewed subset
of 39 discovered candidates and primary Markdown list-item links only. Topic
filters, shareable journeys, mobile refinement and interruption recovery are
tracked next. Source stars and resource availability can change after observation.

Verified locally: 31 tests, catalogue/workflow validation and real browser search
and empty-state checks. Hosted deployment is a separate post-release verification.
