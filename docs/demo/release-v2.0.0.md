# AwesomeAwesomeness 2.0

AwesomeAwesomeness 2.0 makes public Awesome lists—not the projects they happen
to link—the primary product. The stable release carries forward the accepted RC
without changing its catalogue or data digest.

## Capabilities

- auditable public Awesome-list discovery with a minimum of 100 observed stars;
- 6,377 eligible list profiles from 8,373 discovered candidates;
- proposed scope, original categories and derived topic taxonomy for each list;
- observed stars, forks, indexed entries, categories and README-path freshness;
- bounded public contributor credit with explicit sampling and privacy limits;
- searchable, category-filtered in-list content with pinned source links;
- topic, freshness and stars-versus-content dashboards with accessible data;
- exact-value comparison for two to four lists; and
- shareable normalized filters with deterministic reset behavior.

## Delivery and recovery update

The final wave adds a versioned recovery contract and deterministic checks around
the GitHub-backed Agentflow run. The exercised history includes checkpoint/pause,
generation transfer, stale-plan rejection, obsolete-writer fencing, uncertain-result
reconciliation, one idempotent issue projection and transcript-free reconstruction
from committed files plus fetched Git refs.

Protected CI ran the complete application and workflow suites for both integration
and RC promotion. The RC GitHub Release targets exact `main` commit
`c8f563eb9d8f48fa7804b70659687b4c91b90c4d`. Cold Community Cloud acceptance then
verified the exact `v2.0.0-rc.1` footer, explorer, Insights metrics/charts, and the
previously missing `awesome-selfhosted/awesome-selfhosted` profile with 1,300 indexed
entries. A true CDP 390-pixel viewport measured `innerWidth = scrollWidth = 390`
with no overflowing elements.

## Evidence boundaries

The versioned snapshot is dated 2026-09-03 and has digest
`0c9ffd50682687d0071b5e81c58b7dc18ea2b8b2d3a0482cd13daba00d0deeba`.
Counts and freshness are observations, not historical trend claims. Contributor
identities are a bounded public sample rather than an all-time total. Repository
crawling and profile processing ran locally; Streamlit Community Cloud reads only
the committed static snapshot and makes no GitHub or AI calls.

Same-platform council seats simulated stakeholder perspectives and did not constitute
independent or human approval. The user explicitly approved the disclosed exception
for the RC `main` merge. Stable identity and hosted behavior are accepted only when
the stable tag, GitHub Release target and post-promotion public footer are reconciled
independently.
