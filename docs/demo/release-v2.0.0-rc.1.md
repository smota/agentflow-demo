# Recoverable 2.0 release candidate

AwesomeAwesomeness 2.0.0-rc.1 is the complete list-first candidate. It combines
the broad 100-star Awesome-list catalogue, per-list scope and taxonomy, observed
repository/content/freshness metrics, bounded contributor credit, in-list search,
comparison and the Insights dashboard already exercised in the alpha releases.

This candidate adds final delivery capabilities and one responsive correction:

- a GitHub-backed Agentflow run with digest-linked checkpoints on the isolated
  `agentflow-state` branch;
- an exercised generation-0 interruption and generation-1 writer transfer;
- fail-closed stale-plan and obsolete-writer tests;
- a reconciled issue projection applied twice with one created comment;
- transcript-free reconstruction by an ephemeral read-only Codex process;
- committed, deterministic recovery evidence checks; and
- width-bounded dashboard hero typography at 390 pixels.

## Evidence boundaries

The recovery records prove cooperative process replacement and durable GitHub
read-back. They do not prove hostile-host isolation, human review, release identity
or deployment. The RC is accepted only after protected checks, exact tag and GitHub
Release reconciliation, local Streamlit shutdown, and cold hosted desktop/mobile
behavior pass independently.

The snapshot remains 6,377 eligible lists and 1,282,722 indexed entries with data
digest `0c9ffd50682687d0071b5e81c58b7dc18ea2b8b2d3a0482cd13daba00d0deeba`.
Repository crawling and all profile processing remain local; Community Cloud reads
only versioned static data.

This is a prerelease. Stable 2.0.0 requires a second protected promotion and a fresh
cold-hosted acceptance pass; the RC tag alone is not stable or deployment evidence.
