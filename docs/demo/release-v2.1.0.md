# v2.1.0 — Inspect the delivery

AwesomeAwesomeness 2.1 turns the public Delivery view into an interactive AgentFlow case study.
The shipped product remains the evidence surface; the primary story is how roles, deterministic
commands, candidate-bound decisions, handovers and recovery kept three delivery episodes
consistent across sessions.

The page adds:

- a three-episode delivery pulse and role map;
- a deterministic command rail with explicit decision purpose;
- versioned process evidence and current product-snapshot metrics;
- documented verification-suite checkpoints;
- a field-by-field fresh-context reconstruction matrix;
- recovery generation transfer and conflict evidence;
- governed decision replay and a public GitHub evidence explorer; and
- a responsive screenshot gallery whose every displayed image carries the Move the Needle logo
  and visible `movetheneedle.info` watermark.

Private Codex task links are not published. Repository activity is a dated versioned snapshot,
not a live GitHub API feed. The delivery was predominantly single-agent and multi-role;
same-platform advice is not represented as independent human approval. Passing local tests,
GitHub checks, the release and hosted Streamlit behavior remain separate acceptance domains.
