# Explore the Awesome lists themselves

AwesomeAwesomeness 2.0.0-alpha.1 changes the primary experience from linked projects
to the community-curated lists that organize them.

- Discover 1,510 eligible lists from 8,373 public repository candidates, at a 100-star minimum.
- Find previously omitted collections such as awesome-selfhosted without a source allowlist.
- Filter scope/topics, stars, curation state and maintenance; browse cards or a table.
- Explore original categories, search within a list, and open exact upstream sources.
- Share complete discovery and in-list filter context with a visible privacy warning.
- Use a keyboard-accessible responsive design, with honest metrics and source attribution.

This is an early, intentionally partial snapshot. 5,326 candidates await enrichment;
pending is not excluded. Source freshness and contributor counts remain unknown
until observed. Richer profiles, dashboards/comparison and final recovery/stable
release are the next increments—not claimed delivered by this alpha.

All crawling and processing remains local. Free Streamlit hosting reads committed,
digest-verified data only. Snapshot:

Simulated stakeholder review is not human approval. Public deployment and exact
tag/version/digest are verified during release closeout, not inferred from local tests.
