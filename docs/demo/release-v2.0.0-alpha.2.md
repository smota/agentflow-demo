# Complete list profiles

AwesomeAwesomeness 2.0.0-alpha.2 completes the list-profile increment over the
broad 100-star discovery snapshot.

- Classifies 8,373 discovered repositories without a source allowlist: 6,377
  eligible lists, 1,431 pending, and 565 excluded with reasons.
- Restores collections previously hidden by the old top-source approach, including
  `awesome-selfhosted/awesome-selfhosted` with 1,300 indexed entries and 86 original
  categories at its pinned revision.
- Shows the last commit affecting each eligible pinned README, a transparent freshness
  range/index, sampled public contributors, and pinned contribution guidance when found.
- Preserves original taxonomy, selected listed properties, labelled source-data links,
  exact upstream entry/category provenance, and list-first scope/topic proposals.
- Keeps hosted execution offline: the crawler and profile processing run locally;
  Streamlit reads only committed, digest-validated JSON.

The exact candidate contains 8,253 referenced detail shards and data digest
`0c9ffd50682687d0071b5e81c58b7dc18ea2b8b2d3a0482cd13daba00d0deeba`.
All 6,377 eligible profiles completed without pending profile errors. Contributor
observations are capped at the latest 100 commits affecting the pinned README and
retain only public login, profile URL, and observed count. They do not collect email
fields. Source-derived titles and URLs can legitimately discuss email or contain `@`.

The actual recovery exercise interrupted generation H after exactly eight durable
observations. Its 13,588-byte sidecar validated, the main checkpoint remained
byte-identical, the writer lock cleared, and the alpha.1 public digest stayed unchanged.
Resume completed all profiles with four bounded workers. A separate exact-digest
dry-run then removed only unreferenced derived/stale shards.

This remains an early prerelease. Cross-list comparison, aggregate charts and the
final dashboard experience are tracked in issue #23; final recovery/story closeout
and stable promotion are tracked in issue #24. Agent-simulated council advice is not
human approval.
